Comment ça marche ?

Visualiser la base affiche les lignes importées depuis votre Excel en lecture seule. Elle ne contient pas les bouteilles de votre cave.

Ma collection contient exclusivement les bouteilles que vous ajoutez. Sélectionner une référence dans la base préremplit le formulaire, mais l’enregistrement crée une copie indépendante dans votre collection.

Les deux espaces sont enregistrés séparément dans le stockage local de cet appareil.
